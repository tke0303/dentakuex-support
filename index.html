消費税もGTも使える電卓 ／ 見られたくない写真と動画を、その裏に

使い方

アルバムを開く

1
電卓の画面で、決めた番号を入力します
2
右下の ＝ を長押しします（約0.6秒）

番号を間違えても何も起こりません。ただ計算結果が出るだけです。

番号を忘れたとき

設定で「忘れたときのために Face ID でも開けるようにする」を有効にしている場合、AC を2秒長押しすると Face ID で開けます。

共通の解除番号はありません。Face ID の予備鍵を無効にしたまま番号を忘れると、開く方法はありません。開発者にも復元できません。

データについて

保存した写真・動画・書類は AES-256-GCM で暗号化してから保存されます。復号に必要な鍵は端末のキーチェーンにのみ保存され、開発者にも Apple にも中身は読めません。

圧縮も変換もしていません。HEIC は HEIC のまま、4K 動画は 4K のまま保存され、書き出すときも元の形式で戻ります。

サブスクリプションを解約したあとも、閲覧と書き出しはいつでもできます。停止するのは、新しいデータの追加・アルバムの整理・iCloud への同期です。

機種変更するとき

iCloud へのバックアップを有効にしていれば、新しい端末でアプリを入れて同じ番号を入力するだけで戻ります。旧端末は必要ありません。

iCloud キーチェーンを有効にしておいてください。復号の鍵はここを通じて引き継がれます。無効のまま機種変更すると、新しい端末でデータを開けなくなります。

隠せない場所

iOS の仕組み上、次の2か所にはアプリ名が表示されます。家族と同じ Apple ID を使っている場合はご注意ください。

  • 「設定」→ Apple ID →「サブスクリプション」
  • 「設定」→ Apple ID →「iCloud」→「ストレージを管理」

よくある質問

解約したらデータは消えますか

消えません。閲覧と書き出しはそのまま続けられます。

取り込むと元の写真は消えますか

設定によります。既定は毎回確認です。削除を選んでも、本体の「最近削除した項目」に30日間残るので戻せます。

同じ写真を2回入れたらどうなりますか

中身が同じものは追加されません。「保存済みだったので追加しませんでした」と表示されます。

削除したら iCloud からも消えますか

ゴミ箱に入れただけなら残ります（30日間）。「完全に削除」を選んだ時点で、iCloud からも他の端末からも消えます。

写真ライブラリを見られていませんか

見ていません。取り込みには、選んだものだけを渡す仕組みを使っています。写真へのアクセス許可を求めるのは、元のデータを削除するときと、書き出すときだけです。
